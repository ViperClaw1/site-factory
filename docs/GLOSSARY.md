# Глоссарий

**site-factory** — этот монорепозиторий: общий стек, из которого собирается
~20 разных сайтов.

**site01-path-marketplace** — первый сайт фабрики, маркетплейс коллекционных
игрушек Path Animation.

**apps/site-template** — пока не существует в репозитории. Планируемый общий
шаблон сайта, из которого будут стартовать site02..site20. См.
`docs/architecture.md`.

**Directus** — headless CMS на `cms.vcpath.us` (Directus 12.2.0). Сейчас база
`directus` в общем инстансе `shared-infra-postgres`; переезжает в общую базу
коммерции, когда заработает стек Supabase (ADR-008, ADR-002). Через него редактируют контент (`sites`, `pages`, `blocks`,
`collections`, `characters`), каталог, остатки и платёжные ссылки всех сайтов.

**Directus assets URL** — отдельный публичный адрес для медиафайлов Directus
(`assets.vcpath.us`), намеренно отделённый от API-адреса, чтобы будущий
переезд медиа (например, на self-hosted MinIO) не требовал переписывания контента. См.
`docs/env-template.md`.

**Supabase** — Postgres + Realtime + Auth, источник правды для коммерции.
Один self-hosted стек на нашем сервере в Германии (netcup, Нюрнберг) на все
сайты и каналы (ADR-008), миграции в
`packages/db`. RLS привязана к `auth.uid()` через `customers.auth_user_id`.

**Customer (клиент)** — человек в общей базе (`customers`), один на все сайты и
каналы. Отдельная сущность от аккаунта `auth.users`: клиент может существовать
без входа (например, купил по ссылке) и позже привязаться к аккаунту.

**Identity (идентификатор)** — подтверждённый способ связаться с клиентом или
узнать его: email, телефон, Telegram, Google, Apple (`customer_identities`).
Уникален по паре (тип, значение); привязывается только после подтверждения.

**Channel (канал)** — откуда пришла продажа: сайт, Telegram, Facebook,
Instagram, внешний маркетплейс. Хранится в `orders.channel` вместе с
`campaign`; по каналу считается выручка и выделяется остаток.

**Payment link (платёжная ссылка)** — ссылка вида `pay.<бренд>/l/<slug>` на
готовый оффер (товары, цена, канал, кампания, срок, лимит использований).
Создаётся в Directus; checkout по ней проходит без сайта и корзины.

**RLS (Row Level Security)** — политики доступа на уровне БД в Postgres;
в этом проекте гарантируют, что пользователь видит только свои заказы/
wishlist/подписки, а смена статуса (paid/shipped/refunded) — только через
`service_role` на сервере, не через клиентскую запись.

**ISR (Incremental Static Regeneration)** — стратегия рендеринга Next.js;
здесь используется с `revalidate = 0` (по требованию через вебхук), а не по
таймеру.

**RSC (React Server Components)** — модель рендеринга Next.js App Router;
упомянута в контексте CVE-2025-55182 (см. `docs/deployment.md` про версии
зависимостей).

**Turborepo** — оркестратор монорепозитория (кэш задач, граф зависимостей
между `packages/*` и `apps/*`), используется для `build`/`lint`/`type-check`
и для `turbo prune --docker` при сборке образа.

**Coolify** — self-hosted PaaS. Выведен из релизного пути (ADR-009): деплой
только через GitHub Actions, образ собирается на сервере из снимка репозитория
(как у `parser`: `ci-parser` + `pathctl update`).

**pathctl** — серверная утилита развёртывания (`pathctl update`): берёт снимок
репозитория на коммите и собирает образ на сервере, без реестра образов.

**Traefik** — reverse proxy перед всеми сервисами, выпускает и продлевает
TLS-сертификаты автоматически.

**Hyperswitch** — self-hosted платёжный процессор (карты/банковские переводы).

**BTCPay Server** — self-hosted приём криптоплатежей.

**Formance** — внутренний ledger (бухгалтерский учёт транзакций), отдельно от
Supabase `orders`.

**Cloudflare R2** — не используется (решение 12.11: облака для наших данных
нет). Код `packages/lib/src/r2.ts` и переменные `R2_*` переименовываются в общий
S3-клиент и `S3_*`.

**MinIO** — self-hosted S3-совместимое хранилище на нашем сервере для
приватных медиа (цифровые товары, видео курсов); файлы Directus — на локальном
томе (`STORAGE_LOCATIONS=local`).

**Plausible** — не развёрнут; `PlausibleProvider` и прокси `/stats/*` удаляются
из сайтов (ADR-005, 12.11).

**Аналитика** — только self-hosted на нашем сервере или без инструмента
(ADR-005, 12.11). Предложен Umami; облачный PostHog не используется. Деньги и
LTV считаются в базе коммерции.

**gitleaks** — сканер секретов в git-истории, часть CI (`.github/workflows/ci.yml`).
